# 参考｜平台差异手册

**人性不变，评判标准变。**

好奇、共情、身份认同、实用价值——这些底层驱动在哪个平台都一样。
但**同一条内容在两个平台会得到完全不同的分数**，因为它们奖励的东西不同：
小红书奖励「值得存下来」，YouTube 奖励「看得久」。

所以：**定位、人设、表达欲是跨平台的；选题角度、钩子、时长、成败判据是分平台的。**

> ⚠️ 本文是先验假设，不是定论。平台规则一直在变。
> 每条判断都应该被用户自己的 `ledger` 数据证伪——见 `workflows/7-review.md` 的假设回验。

---

## 一、两平台速查

|  | 小红书 | YouTube |
| -------------- | --------------- | ------------------------ |
| 核心指标 | **收藏** | **观看时长 / AVD** |
| 次要指标 | 主页访问、私信 | CTR、订阅转化 |
| 点赞的意义 | 弱 | 弱 |
| 决定生死的位置 | 封面 | 缩略图 + 标题 |
| 标题上限 | **20 字（硬）** | 较宽松（显示约 60 字符） |
| 正文上限 | 1000 字 | 长（描述区可做 SEO） |
| 长尾 | 强 | **最强** |
| 搜索流量 | **高** | **高** |
| 图文 | 常优于视频 | 无 |
| 适合时长 | 图文 / 1–3 分钟 | 8 分钟以上有优势 |
| 内容气质 | 有用 + 有审美 | 深度 + 完整交付 |

---

## 二、小红书

### 什么算好内容

**「值得存下来」**。收藏是这个平台的硬通货，点赞不是。
用户在做决策——买什么、去哪、怎么办——内容要能被存进收藏夹将来用。

| 要素   | 要点                                      |
| ------ | ----------------------------------------- |
| 封面   | 第一生产力。封面文字 ≤10 字，放上方安全区 |
| 标题   | ≤20 字是硬约束，超了会被截断              |
| 关键词 | 搜索占比高，关键词必须前置且直白          |
| 形态   | 图文常优于视频，别默认拍视频              |
| 语气   | 第一人称真实经验，硬广感是原罪            |
| 评论区 | 第二内容场，回复要当内容做                |

### 判成败

```
收藏 / 点赞 > 1        内容有存留价值
主页访问率高           人设立住了
播放低但收藏高         搜索型内容的正常形态，不是失败
```

### 常见误判

- 用播放量判断搜索型内容——等于用跑步成绩评价游泳
- 追求点赞——点赞在这个平台最不值钱
- 把短视频的强节奏搬过来——这里的用户在做决策，不在找刺激

## 三、YouTube

### 什么算好内容

**「值得花时间看完」**。平台优化的是总观看时长，不是点击。
标题党能骗到点击，但 AVD 塌了会被算法惩罚得更狠。

| 要素          | 要点                                           |
| ------------- | ---------------------------------------------- |
| 缩略图 + 标题 | 是一个组合拳，要一起设计，不是两件事           |
| CTR           | 决定有没有机会；AVD 决定还有没有下一次         |
| 时长          | 8 分钟以上有优势，但前提是撑得住               |
| 结构          | 章节、清晰的交付承诺、开头说清「你会得到什么」 |
| 描述区        | 真正的 SEO 阵地，比标签重要                    |
| Shorts        | 独立生态，和长视频的评价标准不通用             |
| 系列          | 订阅转化几乎全靠可预期的系列                   |

### 判成败

```
AVD / 视频时长   留存率，比绝对时长更能说明问题
CTR              2–10% 是常见区间，脱离缩略图谈 CTR 没意义
观看时长总量     平台真正在优化的量
订阅 / 观看      系列做没做起来
长尾曲线         D30/D7 > 1.5 说明搜索价值成立
```

### 常见误判

- 把竖屏短视频直接搬上来当长视频——两套逻辑
- 忽略缩略图——在这里缩略图的权重高于标题
- 用 Shorts 的数据判断频道健康度

## 四、跨平台分发的取舍

**不要一条内容原样发两个平台。**同一个选题内核，两种封装。

| 层                 | 跨平台复用 | 必须分平台 |
| ------------------ | ---------- | ---------- |
| 定位 / 人设 / 禁区 | 复用       | —          |
| 选题内核           | 复用       | —          |
| 角度与切入点       | 部分复用   | 常需调整   |
| 标题               | —          | 分平台     |
| 封面 / 缩略图      | —          | 分平台     |
| 时长与节奏         | —          | 分平台     |
| 成败判据           | —          | 分平台     |

### 一个选题的两种封装

```
内核：「做了三年自媒体，我劝你别辞职」

小红书   《全职做自媒体前，先算这 4 笔账》     图文 · 关键词前置 · 可收藏
YouTube  《我全职做自媒体三年：真实收入与代价》 12 分钟 · 完整交付 · 章节
```

**同一个人，同一个观点，两种说法。**这不是偷懒复制，是翻译。

## 五、平台规则：哪些是真的，哪些是民间传说

### 「账号要垂直」不是平台规则

查遍平台官方规则文件，**没有「垂直度」这个参数**。
平台罚的是**内容违规**（导流 / 无资质 / 虚假信息），**不罚内容跨领域**。

「垂直度不高会限流」只见于运营圈的民间清单——
传播最广的那份（2,449 赞 / 1,024 评）正文把「违规」写成「未归」、
「私信」写成「思信」；另一份同样高赞的清单**完全没提垂直度**。
两份互相打架，都没有出处。

> **含义：「生活 + 职业」这种混合结构在规则层面零风险，不需要向平台求许可。**

同样查无实据的还有：

| 传说 | 实据 |
|---|---|
| 更新频率惩罚 | 无 |
| 断更惩罚 | 无 |
| 删稿 / 改标题惩罚 | 无 |

断更后复更，最坏情况只是**没有粉丝惯性**，**不存在「惩罚」**。

### 导流红线（这个是真的）

| 禁止 | 说明 |
|---|---|
| 传播个人联系方式 | 微信 / 邮箱 / 电话 |
| 发布其他平台的链接、口令、截图、水印、二维码 | — |
| **以明示或暗示方式**诱导用户至私域 | 关键词是「暗示」 |

- **谐音字和图片同样被识别**——官方检测的是**意图**，不是字面
- 简介放联系方式会被**直接清空并计违规**
- ✅ **正常使用站内私信功能不算违规**——官方明确认可，「私你了」这个动作安全

### 特殊行业的资质门槛

部分行业（房产、金融、医疗等）的专业号认证要求**平台所在国的本地资质**。
持境外执照的个人在现行规则下拿不到，**因而也拿不到官方留资组件**。

> **给这类用户做方案时，转化必须 100% 设计在站内私信里。**
> 这是**架构约束，不是可优化项**——不要在方案里留「等认证下来就……」的伏笔。

## 六、配额与诊断按平台各算

配额服务的是**观众体感**，而观众只活在一个平台里。

```
「生活内容 ≥6/10」必须在每个平台各自的最近 10 条里成立
不能两个平台加总算
```

诊断同理：**同一条内容在 A 平台失败、B 平台成功，是常态，不是矛盾。**
先分平台看形状，再判断是内容问题还是适配问题。

| 现象             | 结论                                    |
| ---------------- | --------------------------------------- |
| 两个平台都差     | 内容问题 → 回 `3-topic` / `5-script`    |
| 只有一个平台差   | 适配问题 → 回 `4-hook` 改那个平台的封装 |
| 一个平台明显好   | 可能找到了主场，考虑集中资源            |
