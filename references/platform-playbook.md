# 参考｜平台差异手册

**人性不变，评判标准变。**

好奇、共情、身份认同、实用价值——这些底层驱动在哪个平台都一样。
但**同一条内容在三个平台会得到完全不同的分数**，因为每个平台奖励的东西不同：
小红书奖励「值得存下来」，抖音奖励「看完了还转发」，YouTube 奖励「看得久」。

所以：**定位、人设、表达欲是跨平台的；选题角度、钩子、时长、成败判据是分平台的。**

> ⚠️ 本文是先验假设，不是定论。平台规则一直在变。
> 每条判断都应该被用户自己的 `ledger` 数据证伪——见 `workflows/7-review.md` 的假设回验。

## 一、三平台速查

|                | 小红书          | 抖音             | YouTube                  |
| -------------- | --------------- | ---------------- | ------------------------ |
| 核心指标       | **收藏**        | **完播率**       | **观看时长 / AVD**       |
| 次要指标       | 主页访问、私信  | 评论、转发       | CTR、订阅转化            |
| 点赞的意义     | 弱              | 弱               | 弱                       |
| 决定生死的位置 | 封面            | 前 3 秒          | 缩略图 + 标题            |
| 标题上限       | **20 字（硬）** | 较宽松           | 较宽松（显示约 60 字符） |
| 正文上限       | 1000 字         | 较短             | 长（描述区可做 SEO）     |
| 长尾           | 强              | 弱               | **最强**                 |
| 搜索流量       | **高**          | 中               | **高**                   |
| 图文           | 常优于视频      | 弱               | 无                       |
| 适合时长       | 图文 / 1–3 分钟 | 15–60 秒起号更易 | 8 分钟以上有优势         |
| 内容气质       | 有用 + 有审美   | 强情绪 + 强节奏  | 深度 + 完整交付          |

## 二、小红书

### 什么算好内容

**「值得存下来」**。收藏是这个平台的硬通货，点赞不是。
用户在做决策——买什么、去哪、怎么办——内容要能被存进收藏夹将来用。

| 要素   | 要点                                      |
| ------ | ----------------------------------------- |
| 封面   | 第一生产力。封面文字 ≤10 字，放上方安全区 |
| 标题   | ≤20 字是硬约束，超了会被截断              |
| 关键词 | 搜索占比高，关键词必须前置且直白          |
| 形态   | 图文常优于视频，别默认拍视频              |
| 语气   | 第一人称真实经验，硬广感是原罪            |
| 评论区 | 第二内容场，回复要当内容做                |

### 判成败

```
收藏 / 点赞 > 1        内容有存留价值
主页访问率高           人设立住了
播放低但收藏高         搜索型内容的正常形态，不是失败
```

### 常见误判

- 用播放量判断搜索型内容——等于用跑步成绩评价游泳
- 追求点赞——点赞在这个平台最不值钱
- 把抖音的强节奏搬过来——这里的用户在做决策，不在找刺激

## 三、抖音

### 什么算好内容

**「看完了，还想让别人也看」**。完播率决定能不能进下一个流量池，转发和评论决定池子有多大。

| 要素     | 要点                                 |
| -------- | ------------------------------------ |
| 前 3 秒  | 决定生死，没有第二次机会             |
| 节奏     | 信息密度高，静止画面是流失点         |
| 情绪     | 强情绪、强冲突、强反差比实用性更吃香 |
| 时长     | 起号期短视频更容易跑出来             |
| 互动钩子 | 结尾留争议或提问，评论区是二次分发   |
| 平台玩法 | BGM、挑战、模板可借形式，主题别借    |

### 判成败

```
完播率        第一顺位，低于同类均值就是内容问题
评论 / 播放   互动率，决定流量池上限
转发          最强的推荐信号
涨粉 / 播放   起号期看这个，不看播放绝对值
```

### 常见误判

- 用小红书的「有用」标准做抖音——有用但没节奏，完播率救不回来
- 长尾期待——这里内容生命周期 3–7 天，过了就过了
- 只看播放量——百万播放零涨粉是常态，说明选题没有涨粉属性

## 四、YouTube

### 什么算好内容

**「值得花时间看完」**。平台优化的是总观看时长，不是点击。
标题党能骗到点击，但 AVD 塌了会被算法惩罚得更狠。

| 要素          | 要点                                           |
| ------------- | ---------------------------------------------- |
| 缩略图 + 标题 | 是一个组合拳，要一起设计，不是两件事           |
| CTR           | 决定有没有机会；AVD 决定还有没有下一次         |
| 时长          | 8 分钟以上有优势，但前提是撑得住               |
| 结构          | 章节、清晰的交付承诺、开头说清「你会得到什么」 |
| 描述区        | 真正的 SEO 阵地，比标签重要                    |
| Shorts        | 独立生态，和长视频的评价标准不通用             |
| 系列          | 订阅转化几乎全靠可预期的系列                   |

### 判成败

```
AVD / 视频时长   留存率，比绝对时长更能说明问题
CTR              2–10% 是常见区间，脱离缩略图谈 CTR 没意义
观看时长总量     平台真正在优化的量
订阅 / 观看      系列做没做起来
长尾曲线         D30/D7 > 1.5 说明搜索价值成立
```

### 常见误判

- 把竖屏短视频直接搬上来当长视频——两套逻辑
- 忽略缩略图——在这里缩略图的权重高于标题
- 用 Shorts 的数据判断频道健康度

## 五、跨平台分发的取舍

**不要一条内容原样发三个平台。**同一个选题内核，三种封装。

| 层                 | 跨平台复用 | 必须分平台 |
| ------------------ | ---------- | ---------- |
| 定位 / 人设 / 禁区 | 复用       | —          |
| 选题内核           | 复用       | —          |
| 角度与切入点       | 部分复用   | 常需调整   |
| 标题               | —          | 分平台     |
| 封面 / 缩略图      | —          | 分平台     |
| 时长与节奏         | —          | 分平台     |
| 成败判据           | —          | 分平台     |

### 一个选题的三种封装

```
内核：「做了三年自媒体，我劝你别辞职」

小红书   《全职做自媒体前，先算这 4 笔账》     图文 · 关键词前置 · 可收藏
抖音     开口就是「别辞职，我劝你」→ 冲突     30 秒 · 强情绪 · 评论区吵起来
YouTube  《我全职做自媒体三年：真实收入与代价》 12 分钟 · 完整交付 · 章节
```

**同一个人，同一个观点，三种说法。**这不是偷懒复制，是翻译。

## 六、配额与诊断按平台各算

配额服务的是**观众体感**，而观众只活在一个平台里。

```
「生活内容 ≥6/10」必须在每个平台各自的最近 10 条里成立
不能三个平台加总算
```

诊断同理：**同一条内容在 A 平台失败、B 平台成功，是常态，不是矛盾。**
先分平台看形状，再判断是内容问题还是适配问题。

| 现象             | 结论                                    |
| ---------------- | --------------------------------------- |
| 三个平台都差     | 内容问题 → 回 `3-topic` / `5-script`    |
| 只有一个平台差   | 适配问题 → 回 `4-hook` 改那个平台的封装 |
| 一个平台好其余差 | 可能找到了主场，考虑集中资源            |
