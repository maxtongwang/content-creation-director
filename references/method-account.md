# 方法论｜账号体系

三大体系：账号体系 → 内容体系 → 运营体系。
**顺序即逻辑：先定怎么赚钱，再定拍什么，最后定怎么跑。**

---

## 一、商业定位（第一个问题，不是最后一个）

先分叉：**有没有产品承接？**

| 有产品承接 | 无产品承接 |
|---|---|
| **电商**（原则：少即是多）<br>**咨询** | **广告** |

这一步决定后面所有取舍。做广告变现和做咨询转化，选题标准完全不同。

---

## 二、内容定位

二选一，不能既要又要：

```
主题 IP        人物 IP
（内容为主）    （人为主）
```

判断法：**换个人来做，这个号还成立吗？** 成立 → 主题 IP；不成立 → 人物 IP。

---

## 三、IP 策划（五要素）

| 要素 | 问什么 |
|---|---|
| **身份** | 你是谁？凭什么讲这个？ |
| **场景** | 内容发生在哪？固定还是流动？ |
| **道具** | 有没有一个反复出现的物件？ |
| **态度** | 你的立场是什么？温和还是锋利？ |
| **呈现** | 出镜 / 口播 / b-roll / 图文？ |

**道具**最常被跳过，但它是记忆点最便宜的来源。

---

## 四、账户搭建（四件套）

```
头像 · 昵称 · 头图 · 简介
```

---


### 两条硬规则

**昵称格式：「地点/身份 + 名字」。**
真实样本的一致做法。它承担连续性，**且不占标题一个字**——
这是它比系列名强的地方（见 `method-viral.md`「系列名是个幻影格子」）。

**简介永远不放联系方式。**
微信 / 邮箱 / 电话，含谐音、缩写、截图、二维码，一律不放。
三个转化做得最好的样本账号**无一例外**都没放——这是行业共识，不是疏忽。

⚠️ 例外：**资质编号 / 执照号可以放。**
它不是联系方式，不触发导流规则。见 `references/platform-playbook.md`。

## 五、超级符号（借品牌 CIS）

| MI 理念 | BI 行为 | VI 视觉 |
|---|---|---|
| 你反复讲的那句话 | 你反复做的那个动作 | 你反复出现的那个样子 |

三者要指向同一件事。不一致就没有符号，只有噪音。

## 六、内容体系

### 爆款元素（八个标签）

| | | | |
|---|---|---|---|
| 头牌的 | 反差的 | 怀旧的 | 成本的 |
| 荷尔蒙 | 人群的 | 最差的 | 奇葩的 |

命中越多越好；**一个都没命中**基本不用发。

### 脚本结构（六种）

```
讲故事 · 晒过程 · 教知识 · 聊观点 · 尬段子 · 说产品
```

选一种为主，可掺一种为辅。三种混一起就散了。

### 呈现形式（四选）

```
口述 · 视频+配音 · 图片+配音 · 情景剧
```

## 七、运营体系

### 素材体系
```
素材平台（去哪找）  ·  对标账号（跟谁比）
```

### 运营漏斗诊断 ★ 全框架唯一的诊断工具

四层：**流量 → 兴趣 → 信任 → 成交**

先画出自己的漏斗形状，再对号入座：

| 形态 | 长什么样 | 诊断 | 处方 |
|---|---|---|---|
| **健康型** | 标准倒三角，逐层收窄 | 状态良好 | 可复制，或继续扩大流量 |
| **竹竿型** | 四层等宽且都很窄 | **内容不好** | 优化爆款元素、脚本结构、呈现形式 |
| **雨伞型** | 上宽下极窄 | **没有商业定位**（流量大但转化断层） | 内容多维、原生、高频 |
| **水桶型** | 四层等宽且都很宽 | **商业逻辑好** | 优化爆款元素、呈现形式 |

**用法**：不要先问「怎么办」，先问「我现在长什么样」。形状决定处方。

---

### ★★ 转化 = 闸门，不是流量

**转化只发生在一种结构下：笔记里存在一个「必须私信才能拿到的具体东西」。**

决定性对照（同一作者、同一主题、同一批受众，唯一差别是交付物在不在图里）：

| 做法 | 赞 | 评 | 转化 |
|---|---|---|---|
| 表格**放进图里** | 461 | 50 | **0** |
| 表格**不放图里** | 79 | 25 | **9 条「求表格」**（密度 36%） |

数据差 6 倍，转化差无穷倍——**低的那条赢了**。

#### 反例：赢了辩论，零转化

| 情形 | 结果 |
|---|---|
| 一个 CPA 在评论区逐条硬答到专业法条级别，还主动抛钩问对方情况 | 私信 **0** |
| 1,234 赞 / 1,925 藏 的干货帖 | 转化 **0** |
| 731 赞 / 322 评 的生活爆款 | 转化 **0** |

**写死这条：流量与转化不但脱钩，而且负相关。**
转化需要的不是认同，是**对一个具体交付物的索取**。

内容把话说完了，对方就没有开口的理由。留一个缺口，缺口才是入口。

---

### 真实需求的自然语言长什么样

判断一条内容有没有带来真客户，**不看「专业」「学到了」这类评论**——
那是认同，不是需求。要看有没有出现**索取型 / 定位型**提问。

| 类型 | 实际会出现的话 |
|---|---|
| 索取型 | 「我想要」「我在找」 |
| 定位型 | 「这是哪个」「推荐哪个」 |

注意：真实购买意向的语言**不是**「求推荐从业者」——那句话几乎没人说。

**触发条件只有一个：具体、可辨认的对象（地点 / 物件 / 型号）。**
抽象的市场分析、行业干货、认知型内容**不触发**——它们换来的是「学到了」。
