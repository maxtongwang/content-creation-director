# 方法论｜账号体系

三大体系：账号体系 → 内容体系 → 运营体系。
**顺序即逻辑：先定怎么赚钱，再定拍什么，最后定怎么跑。**

---

## 一、商业定位（第一个问题，不是最后一个）

先分叉：**有没有产品承接？**

| 有产品承接 | 无产品承接 |
|---|---|
| **电商**（原则：少即是多）<br>**咨询** | **广告** |

这一步决定后面所有取舍。做广告变现和做咨询转化，选题标准完全不同。

### ★★ 产品类型直接决定形态（不是选题决定形态）

| 产品 | 卖的是 | 形态 | 打漏斗哪一层 |
|---|---|---|---|
| **服务型**（咨询 / 经纪 / 律师 / 教练 / 设计） | **「跟这个人合作是什么感觉」** | **拍 vlog** | **信任** |
| **资料型**（课程 / 模板 / 报告 / 工具） | **信息本身** | **口播干货 或 图文** | 流量 + 兴趣（收藏） |

**这一条比「哪种形态数据好」优先级更高。**

#### ⚠️ 最常见的误用：拿资料型的算法去评服务型的 vlog

真实失效记录：一个**服务型**账号，我按「每成品分钟换来多少曝光」算 ROI ——
vlog 41 vs 非 vlog 145，于是判定「vlog 用同样的效果收了 3.5 倍的价」，建议少做。

**数据没错，结论错了。**

```
资料型的产出   曝光 / 收藏        —— 每分钟 ROI 是对的度量
服务型的产出   看完的人愿不愿意找你  —— 每分钟 ROI 完全测不到这个
```

**vlog 的成本高是真的，但它买的不是曝光，是信任。**
用曝光去衡量信任层的内容，必然得出「它不划算」——**那是度量错了，不是内容错了。**

#### ⚠️ 但「服务型 → vlog」不等于「要做叙事型长 vlog」

真正的维度不是 **vlog 还是口播**，是 **口播在哪拍、场景给不给信息**：

| | A-roll | 场景 | 成本 | 服务型要的信任 |
|---|---|---|---|---|
| **场景口播（vlog 型）** | 我在说话 | **在一个具体地方，场景本身带信息** | **≈ 桌面口播** | **✅ 主力** |
| 桌面口播 | 我在说话 | 无 | 最低 | 🟡 只够讲情绪与总结 |
| 叙事型长 vlog | 全程剪辑 | 有 | **最高** | ✅ 但留给真事件 |

同一账号实测：

```
5–10 分（多为场景口播）  n=27  中位曝光 774  每千曝光 评 3.66 · 转发 2.39
≥15 分（叙事型长 vlog）  n=14  中位曝光 469  每千曝光 评 2.54 · 转发 1.98
```

**场景口播在曝光、评论、转发三项上全面高于叙事型长 vlog，而成本只有它的零头。**

> **服务型的正确落法是「口播都尽量在场景里拍」，不是「多拍长 vlog」。**
> A-roll 照说，只是不在桌子前说。

> **判据**：先问产品是服务型还是资料型，再看数据。
> 顺序反了，服务型账号会被自己的流量数据劝退到只剩干货 —— 而干货恰恰是**不转化**的那一类
> （见本文「转化 = 闸门」：抽象干货换来「学到了」，不换私信）。

## 二、内容定位

二选一，不能既要又要：

```
主题 IP        人物 IP
（内容为主）    （人为主）
```

判断法：**换个人来做，这个号还成立吗？** 成立 → 主题 IP；不成立 → 人物 IP。

---

## 三、IP 策划（五要素）

| 要素 | 问什么 |
|---|---|
| **身份** | 你是谁？凭什么讲这个？ |
| **场景** | 内容发生在哪？固定还是流动？ |
| **道具** | 有没有一个反复出现的物件？ |
| **态度** | 你的立场是什么？温和还是锋利？ |
| **呈现** | 出镜 / 口播 / b-roll / 图文？ |

**道具**最常被跳过，但它是记忆点最便宜的来源。

⚠️ **选道具要看它带来的是谁。**
一个自带外部流量池的道具（车 / 宠物 / 名牌 / 潮品）会把**那个池子的人**带进来，
不是你的目标观众。单账号 218 条实测：以豪车为道具的那一簇
**中位播放全场第一，零评论率 46%、赞率全场倒数第一。**

> **道具解决「认出你」，不解决「想跟你说话」。**
> 播放涨了、互动质量掉了，是道具选错人的典型信号。

## 四、账户搭建（四件套）

```
头像 · 昵称 · 头图 · 简介
```

---


### 两条硬规则

**昵称格式：「地点/身份 + 名字」。**
真实样本的一致做法。它承担连续性，**且不占标题一个字**——
这是它比系列名强的地方（见 `method-viral.md`「系列名是个幻影格子」）。

**简介永远不放联系方式。**
微信 / 邮箱 / 电话，含谐音、缩写、截图、二维码，一律不放。
三个转化做得最好的样本账号**无一例外**都没放——这是行业共识，不是疏忽。

⚠️ 例外：**资质编号 / 执照号可以放。**
它不是联系方式，不触发导流规则。见 `references/platform-playbook.md`。

## 五、超级符号（借品牌 CIS）

| MI 理念 | BI 行为 | VI 视觉 |

三者要指向同一件事。不一致就没有符号，只有噪音。

### 运营漏斗诊断 ★ 全框架唯一的诊断工具

四层：**流量 → 兴趣 → 信任 → 成交**

| 层 | 观测量 |
|---|---|
| 流量 | 中位播放 / 中位曝光 |
| 兴趣 | 中位赞 |
| **信任** | **独立评论者数 —— 不是评论数** |
| 成交 | 索取型提问数 / 私信数 |

先画出自己的漏斗形状，再对号入座：

| 形态 | 长什么样 | 诊断 | 处方 |
|---|---|---|---|
| **健康型** | 标准倒三角，逐层收窄 | 状态良好 | 可复制，或继续扩大流量 |
| **竹竿型** | 四层等宽且都很窄 | **内容不好** | 优化爆款元素、脚本结构、呈现形式 |
| **雨伞型** | 上宽下极窄 | **没有商业定位**（流量大但转化断层） | 内容多维、原生、高频 |
| **水桶型** | 四层等宽且都很宽 | **商业逻辑好** | 优化爆款元素、呈现形式 |

**用法**：不要先问「怎么办」，先问「我现在长什么样」。形状决定处方。

### ★ 互动集中度 —— 比评论数更早的信号

```
互动集中度 = Top 5 评论者的评论数 ÷ 总评论数
```

**评论数会骗人。**单账号实测：170 条评论来自 68 个人，
**评论 ≥4 条的 12 个人贡献了 61%，单人最高 32 条**（还是另一个博主）。

看起来是「有互动」，实际是**一个熟人圈在回声**。
这时候「提高评论数」是错的处方 —— 缺的不是评论，是**新的评论者**。

| 集中度 | 读法 |
|---|---|
| Top5 占比高、独立评论者少 | 熟人圈。**先解决拉新，不要优化互动话术** |
| Top5 占比低、独立评论者多 | 真实观众。评论数才可以当信任层的代理量 |

### ★★ 转化 = 闸门，不是流量

**转化只发生在一种结构下：笔记里存在一个「必须私信才能拿到的具体东西」。**

决定性对照（同一作者、同一主题、同一批受众，唯一差别是交付物在不在图里）：

| 做法 | 赞 | 评 | 转化 |
|---|---|---|---|
| 表格**放进图里** | 461 | 50 | **0** |
| 表格**不放图里** | 79 | 25 | **9 条「求表格」**（密度 36%） |

数据差 6 倍，转化差无穷倍——**低的那条赢了**。

#### 反例：赢了辩论，零转化

| 情形 | 结果 |
|---|---|
| 一个 CPA 在评论区逐条硬答到专业法条级别，还主动抛钩问对方情况 | 私信 **0** |
| 1,234 赞 / 1,925 藏 的干货帖 | 转化 **0** |
| 731 赞 / 322 评 的生活爆款 | 转化 **0** |

**写死这条：流量与转化不但脱钩，而且负相关。**
转化需要的不是认同，是**对一个具体交付物的索取**。

内容把话说完了，对方就没有开口的理由。留一个缺口，缺口才是入口。

---

### 真实需求的自然语言长什么样

判断一条内容有没有带来真客户，**不看「专业」「学到了」这类评论**——
那是认同，不是需求。要看有没有出现**索取型 / 定位型**提问。

| 类型 | 实际会出现的话 |
|---|---|
| 索取型 | 「我想要」「我在找」 |
| 定位型 | 「这是哪个」「推荐哪个」 |

注意：真实购买意向的语言**不是**「求推荐从业者」——那句话几乎没人说。

**触发条件只有一个：具体、可辨认的对象（地点 / 物件 / 型号）。**
抽象的市场分析、行业干货、认知型内容**不触发**——它们换来的是「学到了」。

#### 单账号 218 条的独立复现

两年半、218 条内容、近 7 万播放，逐条读完 170 条评论：

| 类型 | 条数 |
|---|---|
| 闲聊 | 143 |
| 认同 / 寒暄 | 15 |
| 问 / 索取 | 12 |
| **真实商业需求** | **1** |

那唯一一条来自一支 **156 播放的个人近况视频**。
同期 **24 条专业术语内容（累计 1,501 播放）与 16 条市场分析，索取型提问为 0。**

而 12 条问/索取型的触发物全部对得上原理——
一个具体地点（「这是哪个公园的 trail」）、一个具体身份、一件具体的事、
对方自己手上的一项具体资产。**没有一条来自抽象内容。**
