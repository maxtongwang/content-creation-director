# 方法论｜爆款与起号

---

## 一、爆款的四个必要条件

四条同时成立才可能爆：

1. **用户能看懂** —— 理解成本低
2. **链接的群体足够大**
3. **满足点开的两种需求之一** —— 调动情绪 或 获得信息
4. **能引发互动** —— 重点是评论、转发、@朋友；**点赞收藏不算**

选题自查时逐条打钩，缺任意一条就改。

---

## 二、爆款的三种类型

### 万古同悲｜极致共情
击中大范围共同情感记忆。强度序列：

```
家国苍生 > 社会冷暖 > 生死离别 > 人生失意 ≈ 壮志豪情 > 父母子女 ≈ 男女情爱
```

**补充维度**：除了人类 / 性别 / 民族层面，还有
**身份、职业、年龄、地域**等共同情感记忆。这几个更容易落到具体人身上。

### 惊世骇俗｜极致猎奇或震撼
- 你有一个点和 **99% 的人不一样**
- 你做的事 **99% 的人做不到**

### 打破节奏
在普遍快节奏、吵闹的环境里，用**慢、简、静**让人停下来。

---

## 三、选题两步法

**第一步 · 找选题**
- 先看自己有什么：特别的经历、优点、缺点、极度擅长的事
- 若自认普通，就去看世界：寻找与自己有关的**愤怒、忧愁、矛盾**

**第二步 · 选形式**
- 共情型 → BGM + 画面 / 文案 / 短氛围视频
- 特长特点型 → 完整叙事的中长视频，把事说清楚

**隐藏打法**：立刻结合热点表达，哪怕内容简单也能借势。

---

## 四、平台风向：从抓眼球到抓价值

流量分发周期变了——原本 80% 流量在 24 小时内跑完，现在要 7 天。
含义：内容逻辑从**抓眼球**变成**抓价值**。

**最重要的指标变了：收藏。**

| 内容 | 用户行为 |
|---|---|
| 搞笑 / 美女 / 氛围感 | 点赞 |
| **能学到东西、愿意再看一遍** | **收藏** |

平台主推：中长视频、价值感、获得感、信息密度、干货攻略、深度内容。

---

## 五、起号：爆款视频 vs 爆款系列

起号期最该看的不是播放量，是**粉丝增长量**——做「能引发关注行为」的内容。

### 爆款视频（有判断成本）

| 方向 | 说明 |
|---|---|
| 人设 | 展示身份、成就、经历 → 营造「隐形价值」 |
| 外表 | 美的价值 |
| 人格魅力 | 一条视频看出思维、表达、认知，让用户觉得「你在兼容他」 |
| 攻略型 | ⚠️ **爆了不等于涨粉** |
| 才华技能 | 化妆、做饭、维修、知识、审美 |

**攻略型的陷阱**：单次攻略（某地旅行）→ 搜到、收藏，不关注。
**有延续感的攻略**才涨粉——出了一个食谱，他还想学更多。

**跟热点**：80% 的跟热点爆款没有涨粉意义。唯一有效的是**在热点里展现你这个人**。

### 爆款系列（省去判断成本）★ 更有效

| 类型 | 要点 |
|---|---|
| 剧情系列 | 构建人物 IP 世界观；单期中透露宏大故事框架 |
| 提升系列 | 「用 N 期 / N 天带某类人系统学会某事」 |
| 挑战 / 探索系列 | 未完结叙事 |

共同点：**未完结叙事**或**数字延续感**，让用户想追更。

---

## 六、IP：真实 + 设计

**IP 的本质不是包装，是通过「真实 + 设计」建立信任，降低商业决策成本。**

### 从 ID 开始
1. 有记忆点、顺口
2. 有信息量——别人能从名字判断你是谁、做什么

### 构成
```
真实部分：性格、作风、爱好、特长、身份、习惯、口头禅
设计部分：不是造假，是围绕真实做放大
```

**铁律：人设可以增加，但不能颠覆。**一旦真实底色被推翻，信任就崩。

### 从喜欢到爱上
> 喜欢一个人是喜欢 ta 的优点，爱上一个人是爱上 ta 的缺点。

「缺点设计」要引发共情和心疼，不能伤害他人。

### 创始人 IP：只要你要，只要我有

**「只要你要」六个高共鸣选题**：年少有为 / 大器晚成 / 造梦狂人 / 草根逆袭 / 逆风翻盘 / 苟富贵勿相忘

**「只要我有」讲什么**：成就与如何做到 / 最大挫折 / 正确选择 / 一句话总结成功 / 给年轻人的忠告

**故事大纲**：`成果 → 开局 → 困难 → 转折 → 上升`，再加亲情、爱情、义气增加温度。

## 七、两种博主 × 五种作品目的

| 博主类型 | 靠什么 |
|---|---|
| IP 型 | 身份、经历、话题自带流量（内容能力可弱，但难持续） |
| **内容型** | 选题、策划、创意、拍摄、后期（门槛高，但**普通人更可行**） |

**一条内容不必同时完成所有目标**：

```
数据型 · 涨粉型 · 商业型 · 调性型 · 表达型
```

---

## 八、底层能力（反对拆解爆款）

**大量拆解爆款是假努力。**真正重要的是：

- **选题能力**：热点追踪力、舆情判断力、需求感知力、共情力
- **版本更新意识**：不能一直用旧打法
- **写脚本能力**：重点不是写得细，是**先在脑子里有画面**
- **常识与杂识**：口播形式、BGM、梗、镜头、肢体语言——什么都懂一点

培养方法：少拆多刷、把点赞收藏当素材库、多在脑中「拍画面」、多站在别人视角。

---

## 九、爆款之后 / 数据不好

- **拍出爆款后**：先复制同类内容放大势能，不要急着回应评论或解释方法
- **系列生命周期**：3–6 个月，之后需优化方向
- **数据不好**：先看后台判断是封面点击率 / 跳出率 / 完播率哪一环的问题，**不要立刻删视频**
- **变现时机**：爆款系列出来后先集中涨粉，等热度疲软或 10 万体量再接单

# 十、分镜

## 切镜无因等于零

连续用同款景别（中景接中景）只是重复画面信息。
**每次换镜头必须带来新内容，否则不如不切。**

## 切镜的三种合理依据

切镜前自查，以下**任意一项发生变化**才切：

| 依据 | 例子 |
|---|---|
| **信息改变** | 前镜交代动作，后镜补充细节或场景 |
| **情绪改变** | 平静转紧张、开心转失落 |
| **视角改变** | 客观镜头切人物主观视线 |

## 理由前置公式

```
铺垫  →  切镜  →  兑现
```

前一镜用皱眉、眼神、台词埋下理由，后一镜放出细节解释原因。
**拒绝到点机械切镜**——不靠时长驱动画面，靠镜头内容做转场。

## 3W 原则（新手直接套）

| | 景别 | 作用 |
|---|---|---|
| **Where** | 全景 | 交代环境背景，建立代入感 |
| **Who** | 中景 | 展示人物是谁、在做什么 |
| **What** | 特写 | 放大关键动作或表情 |

## A-ROLL / B-ROLL 分层

```
A-ROLL 主画面：口播、对话、主线 —— 讲清「发生了什么」
B-ROLL 辅助画面：空镜、细节、动作 —— 丰富与转场
```

**剪辑时保留 A-ROLL 的声音，画面切到 B-ROLL** —— 层次感立刻出来。

## 景别作用对照表

```
远景 → 铺环境      全景 → 拍整体人物
中景 → 记录行为    近景 → 捕捉神态      特写 → 放大细节
```
