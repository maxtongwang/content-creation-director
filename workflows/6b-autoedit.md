# 6b · b-roll + 配音 自动化流水线

**何时用**：`form = b_roll_vo`，且手上有素材库检索与剪辑软件的 MCP。

**为什么单独一条**：b-roll + 配音是**产能最高的形态**——
不用出镜、不用打光、不用背稿，素材可以复用，配音可以重录甚至合成。
这条链路是全流程里唯一**可以端到端自动化**的。

**依赖**：`references/mcp-tools.md`
**输入**：`script.yaml`（必须有 `vo_segment` 和镜头表）
**产出**：`edit-plan.json` + 已搭好的时间线

---

## 一、三种配音，不是两种

**「AI 配音」不是一件事。**用陌生人的合成音、用你自己的克隆音、真人现录——
这三者对账号的影响完全不同，不能用同一张表判断。

| 模式 | 是谁的声音 | 身份 | 语气 / 气口 |
|---|---|---|---|
| **真人现录** | 你 | 你 | 你 |
| **本人声音克隆** | 你 | **你** | 念稿感 |
| 通用合成音 | 陌生人 | 不是你 | 无 |

**本人克隆 + b-roll 里有你的脸 = 身份问题基本解决。**
声音是你的、脸是你的、话是你写的——这和「用一个陌生播音腔配空镜」是两回事。

### 那还剩什么问题

只剩一个，但它是真的：**克隆音是在念稿，不是在说话。**

既有规则说「保留口误、停顿、被打断——人味儿即可信度」。
克隆复制的是**音色**，不是**说话方式**：它不卡壳、不改口、没有气口。
听感上像你在读一段写好的字，因为事实就是如此。

**这不是身份问题，是表演问题。**处理办法在第三节。

### 判断表（按模式分开看）

| 内容类型 | 真人现录 | 本人克隆 | 通用合成音 |
|---|---|---|---|
| 搜索型 / 攻略 / 教程 | 可以 | **可以** | 可以 |
| 榜单 / 盘点 / 资讯 | 可以 | **可以** | 可以 |
| 空镜氛围向 | 可以 | **可以** | 可以 |
| 日常 / vlog 旁白 | 可以 | **可以** | 不要 |
| 人设类 / 观点类 | 可以 | **可以，但见第三节混录** | 不要 |
| 态度类（会拒绝什么） | 可以 | **不要** | 绝对不要 |
| 商业转化类 | 可以 | 谨慎 | 不要 |

**态度类为什么连本人克隆也不行**：这类内容的价值全在语气——
「这个单我不接」说得硬还是软，决定观众信不信你有底气。
`6-edit.md` 已把「态度类口播的语气匹配」列为**永远保留人工的四项之一**，
克隆音改变不了这条。这几句自己录，其余用克隆，**一条片子里混用完全可以**。

### self_presence 怎么算

**「b-roll 里有我的脸」正好解决了这条。**
`self_presence` 要的是**画面里有你**，与配音是不是现场录的无关：

```
本人入画 ≥15%       用你自己的素材，无声出镜也算
入画间隔 ≤90 秒     b-roll 里穿插你的镜头
HOOK 或 CLOSE 有你  首尾各留一个你的画面
```

三条满足即通过，**不因为配音是克隆的而额外扣分**。

反过来说：如果 b-roll 里**没有**你的脸，那不管配音是谁的声音，
这条都不满足 `self_presence`——问题出在画面，不在声音。

### 合规

AI 合成语音在多地有**标识要求**，各平台也有自己的 AI 内容标签。
用克隆音发布前，把对应要求写进 `profile.compliance`，按平台各自规则标注。

**这是本人声音、本人授权，不涉及冒充**——要处理的是「是否需要标注为合成」，
不是「能不能用」。

## 二、流水线全貌

```
script.yaml
   │  vo_segment（每段口播文本）
   ▼
配音音频  ← 真人录 / 本人克隆音 / 两者混录
   │
   ▼
按段找 b-roll  ← VideoSemantics: find_broll(narration=每段文案)
   │
   ▼
edit-plan.json  ← 本 skill 产出，带 clip 路径与 in/out
   │
   ▼
DaVinci 建时间线  ← 导入 → 排轨 → 铺配音 → 生成字幕
   │
   ▼
人工通看  →  渲染
```

**每一步都能单独退化成人工。**没有素材库就自己挑素材，
没有 DaVinci MCP 就输出 `edit-sheet.md` 自己剪。

## 三、配音

### 真人录音（默认）

按 `script.yaml` 的 `vo_segment` 逐段录，或一条过之后按语义切。
处理方式follow `style.edit.vo_handling`：全保留 / 删长静默 / 紧凑。

### 本人声音克隆（推荐路线）

**一次性建好，长期复用。**

| 步骤 | 做法 |
|---|---|
| 采样 | **至少 10 秒清晰人声**，实际给 1–2 分钟更稳；用你平时说话的状态，不要播音腔 |
| 建声音 | 走 TTS 工具的克隆流程（如 `clone_voice`）。**要花额度且需显式授权**——会先返回费用与授权声明，看清再同意 |
| 记录 | 声音名写进 `profile.styles.<风格>.fixed_elements.voice`，以后直接用，不再重建 |
| 生成 | 按 `vo_segment` **逐段**生成，不要整篇一次出 |

**采样质量决定一切。**拿带混响的房间录音、带背景音乐的素材去克隆，
出来的每一条都会带着那个底噪，而且改不掉。

### 一个必须知道的限制

**克隆音一般只能做文本转语音（TTS），不能做「用我的声音重配我的录音」（STS）。**

也就是说：你**不能**先随口录一条粗的、再让克隆音去「翻唱」它、保留你的语气节奏。
你只能给它文本。这正是念稿感的技术来源——**它拿到的是字，不是你的表演。**

### 怎么把念稿感压下去

| 做法 | 说明 |
|---|---|
| 用口语写稿 | 写完**念一遍**，念着别扭就改。见 `references/hot-and-language.md` |
| 短句 | 一句一个意思；长句会暴露合成音换气不自然 |
| 显式断句 | 该停的地方分段，别指望它自己找气口 |
| **混录** | 态度类、观点类的关键几句**自己录**，其余用克隆 |
| 语速对齐风格 | 配合 `style.edit.pace`，快节奏风格别用慢速参数 |

**混录是最优解。**全片克隆最省时间，但把最需要语气的三五句自己录，
成本只多两分钟，可信度差很多。哪几句自己录，记进 `edit-plan.vo.human_recorded_segments`。

### 通用合成音

只在第一节判断表允许的行使用。规则同上，且**固定一个音色**——换音色等于换人设。

### 逐段生成很重要

整篇生成拿到的是一整条音频，还得再切一次；
分段生成天然对齐 `vo_segment`，直接就是剪辑段。

## 四、按段找 b-roll

这是整条链路里**省时间最多的一步**。

`find_broll(narration, limit)` 接收一段旁白文本，返回排序过的候选片段。
对每个 `vo_segment` 调一次：

```
for 每个 vo_segment:
    候选 = find_broll(narration=该段文案, limit=5)
    按第五节的规则选 1–3 个
```

### 找不到合适的怎么办

按顺序降级，**不要停下来问**：

| 顺序 | 做法                                                      |
| ---- | --------------------------------------------------------- |
| 1    | `find_broll` 换个说法再试一次（用画面描述，不用抽象概念） |
| 2    | `find_clips(description=...)` 直接描述想要的画面          |
| 3    | `search_clips(query=...)` 按关键词/字幕/OCR 搜            |
| 4    | 记进 `shoot_needed`，作为补拍清单交给用户                 |

**第 4 步是合格结论。**素材库里没有就是没有，
硬凑一个不相干的画面比留空更糟——那正是「为凑时长重复 b-roll」的变种。

### 先确认库是活的

开工前 `library_status()` 看一眼索引量。库是空的就直接转人工，
不要对着空库反复搜。

---

## 五、选镜（沿用 6-edit 的规则，不另起一套）

`find_broll` 给的是**候选**，不是决定。仍然按 `6-edit.md` 第四步筛：

```
1. size + subject 与脚本镜头表匹配
2. cut_reason 成立（相邻镜头之间有信息/情绪/视角变化）
3. value=hero 优先于 broll
4. motion ≠ static（尤其 HOOK）
5. 单镜时长落在 style.edit.avg_shot_sec 区间
6. 相邻两镜 size+subject 相同 → 无效切镜，换一个
```

**语义匹配 ≠ 剪辑正确。**检索模型只知道「这段画面和这句话有关」，
不知道你上一镜刚用过同样的景别。第 6 条只能由本环节把关。

---

## 六、落成 edit-plan.json

结构见 `templates/edit-plan.template.json`。b-roll + 配音要额外填：

```json
"vo": {
  "mode": "cloned_self",
  "voice": "<固定声音名>",
  "human_recorded_segments": ["vo-05"],
  "segments": [
    { "id": "vo-01", "text": "...", "audio": "<路径>", "duration_sec": 6.2 }
  ]
},
"timeline": [
  {
    "seq": 1, "role": "HOOK", "vo_segment": "vo-01",
    "shots": [
      { "clip_id": "<素材库 ID>", "source_path": "<绝对路径>",
        "in": 0.0, "out": 2.4,
        "size": "特写", "subject": "detail",
        "type": "B-ROLL", "cut_reason": "信息" }
    ]
  }
]
```

**`source_path` 必须是绝对路径**——剪辑软件要靠它导入，相对路径会失败。

## 七、交给 DaVinci

按这个顺序调用，**每步失败就停下来报错，不要跳过继续**：

| 步  | 工具                                              | 做什么                       |
| --- | ------------------------------------------------- | ---------------------------- |
| 1   | `add_items_to_media_pool_from_storage`            | 把用到的素材与配音导入媒体池 |
| 2   | `create_timeline` 或 `create_timeline_from_clips` | 建时间线，命名用 `plan_id`   |
| 3   | `append_to_timeline`                              | 按 `timeline` 顺序逐镜追加   |
| 4   | `insert_audio_to_current_track`                   | 铺配音轨                     |
| 5   | `timeline_create_subtitles_from_audio`            | 从配音自动生成字幕           |
| 6   | 人工通看                                          | **不可跳过**                 |
| 7   | `add_render_job` → 渲染                           | 通看之后才渲                 |

### 关键细节

**in/out 靠 `clip_infos` 传。**`append_to_timeline` 接收 `clip_infos`
（Resolve 的 clipInfo 结构，含起止帧），不是只给个片段 ID 就完事——
edit-plan 里每镜的 `in`/`out` 要换算成帧数填进去，否则整段素材会被原样铺上。

**帧数换算要用时间线帧率**，不是素材帧率。混帧率素材是这一步最常见的坑。

**字幕是白赚的。**`timeline_create_subtitles_from_audio` 直接从配音轨生成，
比手打字幕省一大截。生成完按 `style.edit.subtitle` 调样式（无 / 基础 / 花字）。

**渲染前必须人工通看。**这是 `6-edit.md`「永远保留人工的四项」里的第四项，
自动化到这里为止。

## 八、退化路径

任何一环缺工具都能继续走：

| 缺什么       | 退化成                                              |
| ------------ | --------------------------------------------------- |
| 素材库 MCP   | 人工挑素材，`edit-plan` 里填手工路径                |
| 剪辑软件 MCP | 只出 `edit-plan.json` + `edit-sheet.md`，用户自己搭 |
| TTS          | 真人录音（本来就是默认）                            |
| 全都没有     | 退回 `6-edit.md` 分支 B，纯人工                     |

**不要因为链路不完整就不做。**能自动一半就自动一半。

---

## 九、告警（在 6-edit 那张表之外追加）

| 告警 | 触发条件 |
|---|---|
| 配音模式用错内容 | `vo.mode` 与第一节判断表冲突（如态度类用了克隆音） |
| 画面里没有本人 | b-roll 全是空镜或素材站素材，不满足 `self_presence` |
| 声音不一致 | `vo.voice` 与该风格历史用的不同 |
| 关键句未自己录 | 态度类 / 观点类语句落在克隆段里，`human_recorded_segments` 为空 |
| 未按平台标注 | 用了合成音但 `profile.compliance` 没有对应平台的标识约定 |
| 素材复用过密 | 同一 `clip_id` 在近 N 条内容里反复出现 |
| 帧率不一致 | 素材帧率与时间线帧率不同，未做换算 |
| 字幕未校对 | 自动字幕未经人工过一遍（专有名词最容易错） |

---

## 出口

1. `edit-plan.json`（含 `vo` 段与 clip 路径）
2. DaVinci 里搭好的时间线
3. 补拍清单（`find_broll` 找不到的那些）
4. 告警列表

**渲染不是本环节的出口——人工通看才是。**
