# 2 · 人设 IP 与验证

**产出**：`profile.yaml` 的 `ip` 段
**方法论**：`references/method-viral.md` IP 章

---

## 核心定义

**IP 的本质不是包装，是通过「真实 + 设计」建立信任，从而降低商业决策成本。**

---

## 一、拆真实与设计

```
真实部分：性格、作风、爱好、特长、身份、习惯、口头禅
设计部分：不是造假，是围绕真实做放大
```

逐项问用户拿**具体事例**，不要形容词。

```
❌ 你性格怎么样？
✅ 上周有没有哪件事，你的处理方式跟别人明显不一样？
```

---

## 二、验证：三道检查 ★ 本阶段的核心

任何人设方案必须过这三关。

### 检查一 · 颠覆检查

> **人设可以增加，但不能颠覆。**

问：**如果观众明天发现你其实不[人设关键词]，会怎样？**

- 「会觉得我夸张了」→ 可以，属于设计放大
- 「会觉得我在骗人」→ **不可以，推倒重来**

一旦真实底色被推翻，信任关系就崩，且不可修复。

### 检查二 · 可持续检查

问：**这个人设你能演三年吗？**

具体化：
- 这个身份你现在每天真的在做吗？
- 这个态度在你心情不好的那天还成立吗？
- 这个场景一年后还在吗？

**现在不做的事，只能当注脚，不能当人设。**

### 检查三 · 缺点检查

> 喜欢一个人是喜欢 ta 的优点，爱上一个人是爱上 ta 的缺点。

问：**你有什么无伤大雅的缺点可以露出来？**

要求：
- 引发共情或心疼 ✅
- 伤害他人 ❌
- 假装的缺点（「我太努力了」）❌ —— 观众一眼看穿

没有缺点的人设只能被喜欢，不能被信任。

---

## 三、创始人 / 有生意的人：只要你要，只要我有

若用户是创始人、老板、专业服务者，用这套：

**「只要你要」——六个高共鸣选题**

| 选题 | 适合谁 |
|---|---|
| 年少有为 | 起步早、有成绩 |
| 大器晚成 | 转行、中年起步 |
| 造梦狂人 | 在做别人不敢做的事 |
| 草根逆袭 | 出身普通 |
| 逆风翻盘 | 失败过又起来 |
| 苟富贵勿相忘 | 带过人、帮过人 |

挑**真实成立**的一到两个，不成立的不要硬套。

**「只要我有」——讲什么**
1. 你的成就，以及如何做到
2. 你的最大挫折
3. 你的正确选择
4. 一句话总结你的成功
5. 给年轻人的一句忠告

**故事大纲**：`成果 → 开局 → 困难 → 转折 → 上升`
再加**亲情 / 爱情 / 义气**增加温度。

---

## 四、身份露出的配额

**身份靠简介承载，不靠每条内容重复。**

```
简介       → 说明你是谁（主要）
系列名     → 名字里已经有了
固定标签   → 每条自动带
主页合集   → 证明你懂
内容本身   → 只负责好看
```

**per_post_identity_hook 是上限不是下限**：建议 ≤3/10 条，且只在自然时提。

强行在每条内容里拐回主业，内容就变成广告了。

## 交付自检

- [ ] 真实部分每一项都有具体事例支撑
- [ ] 过了颠覆检查
- [ ] 过了可持续检查
- [ ] 有一个真实的、无伤大雅的缺点
- [ ] 身份露出定了上限，不是下限
