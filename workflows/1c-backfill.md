# 1c · 逆向导入（有经验用户专用）

**何时用**：用户已有账号、有内容、有数据。

**问题所在**：让老手从零回答一遍定位问题是重复劳动，而且他的**实际定位藏在已发内容里**，
不藏在他的自我描述里——两者经常不一致，而不一致本身就是最有价值的发现。

**原则：先读内容，再问人。已有答案的不问。**

---

## 一、能拿到什么就读什么

| 来源 | 能反推出 |
|---|---|
| 主页简介 + 昵称 | 声称的定位、超级符号 |
| 近 20 条标题 | 实际的选题倾向、句式习惯 |
| 数据（播放/涨粉/收藏） | 哪类内容真的有效 |
| 高赞评论 | 观众实际认可什么 |
| 已有转写/字幕 | 语言习惯、口头禅、观点 |

拿不到就让用户贴——截图、复制文字、导出 CSV 都行。

---

## 二、反推 profile 的四步

### 第一步 · 从数据反推支柱
按内容主题聚类，看每类的**涨粉率**（不是播放量）。

```
高涨粉 + 高频 → 实际的 A 层支柱
高播放 + 低涨粉 → 陷阱（多半是攻略型或蹭热点）
低播放 + 高收藏 → 搜索型内容，别用推荐型标准判断
```

### 第二步 · 从标题反推句式习惯
把近 20 条标题归类：身份反差 / 结果悬念 / 日常切片 / 直白说明。
看哪种句式的点击率最好——那是这个账号已被验证的钩子。

### 第三步 · 从评论反推观众认知
观众叫他什么？夸他什么？问他什么？

**观众的称呼就是实际人设**，可能和他自己写的简介完全不同。

### 第四步 · 找断层 ★ 最有价值的一步

对比三样东西：

```
他说的定位（简介）
他做的内容（实际发的）
观众的认知（评论里的称呼和提问）
```

三者不一致的地方，就是问题所在：

| 断层 | 含义 | 处方 |
|---|---|---|
| 说的 ≠ 做的 | 定位没落地 | 改简介 或 改内容，二选一 |
| 做的 ≠ 观众认知 | 内容传达失败 | 回 4-hook，钩子没对准 |
| 说的 ≠ 观众认知 | 门面和实质脱节 | 回 1-account 重做商业定位 |

---

## 三、只问补不齐的

读完之后，**只问三件事**（数据里读不出来的）：

1. **靠什么赚钱 / 想靠什么赚钱？** —— 商业定位数据里看不出来
2. **有什么是你不想做的？** —— 禁区必须本人说
3. **哪条内容你自己最满意但数据一般？** —— 找出他的表达欲所在

第 3 问尤其重要：**没有表达欲，长期做不下去。**

---

## 四、老手的跳步许可

有经验用户可以跳过某些阶段，但**这三件事不能跳**：

- [ ] `forbidden_topics` 必须有（老手也经常没想清楚不做什么）
- [ ] 商业定位必须具体到「卖什么给谁」
- [ ] 风格档案必须建（见 `8-styles.md`）—— 老手往往已有多种风格，只是没显式定义

其余可以直接从 `3-topic` 或 `7-review` 切入。

---

## 五、逆向导入的边界 ★ 不能跳的一步

**⚠️ 逆向导入只能反推「数据层」。价值观层必须补做 `2-ip`，不能跳过。**

| 层 | 能不能从已发内容反推 |
|---|---|
| 数据层（支柱、内容线、句式偏好） | 能，而且比问出来准 |
| 价值观层（态度、边界、语气、禁区） | **不能** |

数据能告诉你他**做过什么有效**，告诉不了你他**愿意成为什么样的人**。
已发内容里的语气，可能只是他当时随手写的，不是他认可的自己。

**跳过的后果**：产出一份数据上正确、但不像本人的 profile——
每条内容都合规、都命中支柱，就是读起来不像他。而且这种偏差很难被发现，
因为每一项单看都对。

---

## 出口

产出：
1. 一份**反推的 profile.yaml**（标注哪些是推断、哪些是本人确认）
2. 一份**断层报告**（说的 / 做的 / 观众认知 三者的差异）
3. 建议的切入阶段
4. **必做**：`2-ip` 补价值观层（`tone` / `forbidden_sentences` / `surface_rule`）
   —— 这一项不能标记为已完成后跳过
