# 1b · 素材挖掘（零基础用户专用）

**何时用**：用户说「我没什么好拍的」「我很普通」「不知道自己有什么」。

**问题所在**：`1-account` 的「先看自己有什么」对新手是死路——
他之所以来问，就是因为不知道自己有什么。

**解法：不要问「你有什么」，问具体的、有答案的事实。**

---

## 铁律

```
❌ 你的优势是什么？          → 答不出来
❌ 你有什么特别的经历？      → 「我很普通」
✅ 上周你花时间最多的三件事是什么？   → 一定有答案
```

**所有问题必须是「有确定答案的事实」，不是「需要自我评价的判断」。**

---

## 一、六个方向的事实挖掘

每个方向问 2–3 个具体问题，不做评价，只记录。

### 时间去哪了
- 上周花时间最多的三件事？
- 有没有什么事，你做的时间比周围人都长？
- 周末通常在做什么？

### 别人问你什么
- 最近三个月，有人问过你什么问题？
- 朋友遇到什么事会想到找你？
- 有没有什么事你解释过很多遍？

### 你的不满
- 你所在的行业/圈子里，什么事让你觉得离谱？
- 有没有什么「大家都这么做但其实不对」的事？
- 最近一次生气是因为什么？

### 你的代价
- 你为什么事付出过明显代价（钱、时间、关系）？
- 有没有什么坑是你踩过、别人还在踩的？
- 花过最不值的一笔钱是什么？

### 你的门槛
- 有什么事你做起来比别人省力？
- 有什么工具/技能你用得比周围人熟？
- 有没有什么资源是你有、别人没有的？（人脉、场地、设备、信息）

### 你的位置
- 你每天会经过哪些地方？
- 有没有什么场景是别人进不去、你能进的？
- 你身边有什么别人看不到的东西？

---

## 二、从事实到内容支柱

收集完事实后，做三件事：

### 第一步 · 找交叉
```
「花时间多」∩「别人会问」  → 强支柱（有兴趣 + 有需求）
「不满」∩「付出过代价」     → 强观点（有立场 + 有资格）
「门槛」∩「位置」           → 独家内容（别人拍不了）
```

### 第二步 · 反差检查
把事实两两组合，找**不该同时出现在一个人身上**的组合。

```
[身份 A] + [行为 B] = 反差
```

反差是最便宜的记忆点。这也是「惊世骇俗」类爆款的原理：
**你有一个点和 99% 的人不一样。**

### 第三步 · 可持续检查
对每个候选支柱问：**这件事你下个月还在做吗？明年呢？**

不在做的 → 只能当一次性选题，不能当支柱。

---

## 三、最小可行开始

新手最容易死在「准备阶段」。给一条**今天就能拍**的路径：

```
1. 从挖掘出的事实里，挑一件「今天正好会发生」的
2. 用最低成本形式：手机 + 一镜到底口播，或 b-roll + 配音
3. 不做封面设计，用现场最好看的一帧
4. 发出去，不改
```

**第一条内容的目的不是爆，是打破「还没准备好」的循环。**

告诉用户：起号是一夜之间，不是日积月累。
一条数据不好就换方向，不要坚持。

---

## 出口

产出一份**候选支柱清单**（3–5 个），带：
- 支撑它的具体事实
- 归到 A/B/C 哪层
- 能不能持续

然后回 `1-account` 继续填 `profile.yaml`。
