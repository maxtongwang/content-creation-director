# 5 · 脚本与分镜

**输入**：`topic-card.yaml`（含 hook）
**产出**：`script.yaml` —— 这是全流程信息密度最高的文件，直接决定剪辑质量
**方法论**：`references/method-viral.md` 分镜章、`references/method-account.md` 内容体系章

---

## 一、选脚本结构（六选一为主）

```
讲故事 · 晒过程 · 教知识 · 聊观点 · 尬段子 · 说产品
```

**选一种为主，最多掺一种为辅。三种混一起就散了。**

| 结构 | 主线是 | 适合 |
|---|---|---|
| 讲故事 | 时间线 | 经历、案例、创始人 |
| 晒过程 | 步骤 | 工作日常、制作、跟进 |
| 教知识 | 逻辑 | 干货、词条、攻略 |
| 聊观点 | 论证 | 立场、行业判断 |
| 尬段子 | 包袱 | 轻松内容 |
| 说产品 | 卖点 | 转化 |

---

## 二、口播主干（不是逐字稿）

**先写骨架，不写逐字稿。**逐字稿会被念得不像人话，而且锁死时长。

### 四段骨架

| 段 | 作用 | 引导问题 |
|---|---|---|
| **HOOK** | 让人停下 | 此刻最反常/最具体的一件事是什么？ |
| **SETUP** | 交代处境 | 我在哪、要干嘛、为什么是今天 |
| **BODY** | 讲透 | 3–5 件事，每件一段，讲完一件再下一件 |
| **CLOSE** | 收 | 今天最真实的感受 或 一句判断 |

**BODY 的段数由内容决定，不由目标时长决定。**

### 口播质感

- 保留口误、停顿、被打断——那是可信度
- 短句，一句话一个意思
- 具体优于抽象

## 三、分镜（本阶段的核心产出）

**每一个口播语义段，配 1–3 个镜头。**

### 切镜三依据（切之前自查）

以下**任意一项发生变化**才切：

| 依据 | 说明 |
|---|---|
| 信息改变 | 前镜交代动作，后镜补充细节或场景 |
| 情绪改变 | 平静转紧张、开心转失落 |
| 视角改变 | 客观镜头切人物主观视线 |

**切镜无因等于零**——同款景别连接只是重复信息，不如不切。

### 理由前置公式

```
铺垫  →  切镜  →  兑现
```

前一镜埋理由（皱眉、眼神、台词），后一镜放出解释。
**拒绝到点机械切镜**——靠镜头内容做转场，不靠时长。

### 3W 默认模板（新手直接套）

```
Where 全景 → 交代环境
Who   中景 → 展示人物在做什么
What  特写 → 放大关键细节
```

### A-ROLL / B-ROLL 分层

```
A-ROLL：口播、对话、主线 —— 讲清「发生了什么」
B-ROLL：空镜、细节、动作 —— 丰富与转场
```

剪辑时**保留 A-ROLL 的声音，画面切到 B-ROLL**。

### 若本条是 b-roll + 配音（无完整出镜）

额外满足：
- 本人画面间隔 ≤90 秒
- HOOK 或 CLOSE 至少一处本人入画
- 本人入画时长占比 ≥15%
- **必须含一处只有本人能说的具体经验**（第一人称细节）

最后一条是关键。没有它，b-roll 内容三个月后就跟满大街的口播号一样。

## 四、镜头表字段

每个镜头必须写清（这是 `edit-plan` 的原料）：

```
shot_id      编号
role         HOOK / SETUP / BODY-n / CLOSE
type         A-ROLL / B-ROLL
size         远景 / 全景 / 中景 / 近景 / 特写
subject      self / 物 / 环境 / 他人
motion       固定 / 手持 / 运动
cut_reason   信息 / 情绪 / 视角      ← 没有理由就不该有这个镜头
audio        同期声 / 环境音 / 静音
vo_segment   对应哪一段口播
note         要拍到什么
```

## 五、拍摄清单（给用户带出门用）

从镜头表反向汇总：

```
地点清单     去哪几个地方
必拍镜头     不拍就补不回来的
备用镜头     有余力再拍
道具         profile 里定的那个道具带了吗
注意事项     隐私打码、授权、光线
```

- [ ] b-roll 条目满足 self_presence 四条
