# 1 · 账号定位

**产出**：`profile.yaml`（全流程地基）
**方法论**：`references/method-account.md`

---

## 顺序不能改

```
商业定位 → 内容定位 → IP 策划 → 账户搭建 → 超级符号
（怎么赚钱）（拍什么）  （人设）   （门面）    （记忆点）
```

**商业定位排第一**。做广告变现和做咨询转化，后面每一步的取舍都不同。

---

## 第一步 · 商业定位

问：**你有产品要卖吗？**

| 有 | 无 |
|---|---|
| 电商（原则：少即是多）<br>咨询 | 广告 |

追问到具体：卖什么、客单价、谁买、多久买一次。

**若同时有多个变现目标**，做合并检查：

> 「这几个目标，能不能用同一批内容覆盖？」

多数人的多个目标能归成**两条内容线**，各自溢出覆盖另一个。
目标数 ≠ 内容线数——这一步能省一半工作量。

---

## 第二步 · 内容定位

```
主题 IP（内容为主）    人物 IP（人为主）
```

判断法：**换个人来做，这个号还成立吗？**

---

## 第三步 · IP 策划（五要素）

| 要素 | 追问 |
|---|---|
| 身份 | 你是谁？凭什么讲这个？**你每天真的在做这件事吗？** |
| 场景 | 内容发生在哪？固定还是流动？ |
| 道具 | 有没有一个能反复出现的物件？ |
| 态度 | 温和还是锋利？你会不会拒绝什么？ |
| 呈现 | 出镜 / 口播 / b-roll / 图文？ |

**身份那一问是关键**。经常问出矛盾——有人说自己是某身份，但不参与日常。
**可信度身份 ≠ 日常工作身份**：前者只配一句话背书，撑不成内容。

---

## 第四步 · 逼出禁区 ★ 最重要，不能跳

依次问：

1. 你的身份里，有哪部分是真的但你不想做成内容的？
2. 有什么是别人以为你会做、但你其实不做的？
3. 过去的职业、放弃的爱好、不参与的业务环节，有哪些？
4. **什么内容你发出去会心虚？**

每条追问一句：**「这个是完全不提，还是可以当注脚提一句？」**

分两类记录：
- `forbidden_topics` —— 完全不做
- `identity_fragments` —— 只做注脚，带 `usage` 和 `max_per_month`

**第 4 问的答案往往最有价值。心虚感几乎总是指向身份不实。**

一份没有 `forbidden_topics` 的 profile 是废的。

---

## 第五步 · 内容支柱与爱好分层

列出真正在做、拍得出来的爱好/领域，按**离成交多远**分三层：

| 层 | 定义 | 用法 |
|---|---|---|
| A | 能自然桥接到变现主题 | 主推，转化 |
| B | 拉泛流量，不指望转化 | 主推，拉新 |
| C | 只做背景质感 | 不单独成篇、不进标题 |

再给每项标**服务哪条内容线**。

**硬规则：每月只主推 2 个**（建议 1A + 1B，且两条线各覆盖一个）。
全都做支柱等于没有支柱。

---

## 第六步 · 账户搭建与超级符号

四件套：头像 · 昵称 · 头图 · 简介

**昵称两标准**：有记忆点且顺口、有信息量。

**简介是身份的主要承载体**——身份靠简介说清，不靠每条内容重复。
必含：职业 / 地点 / 差异化 / 资质。禁用：欢迎咨询、全程服务、求关注。

**超级符号**：MI 理念 · BI 行为 · VI 视觉，三者指向同一件事。

---

### 顺序设计：feed 不露职业，主页才露

对不想一上来就暴露职业的用户很有用：

```
feed 层不露职业（昵称是地点 / 生活向）
        ↓
主页层露职业（简介 + 资质编号）
```

效果是「**点进来才知道他是干什么的**」。这不是妥协，是可设计的顺序。

**代价要说清楚**：昵称不带职业 = **放弃被搜索找到**。
此时**平台 ID（redId 等）成为唯一还能承担可搜索性的位置**——
它不出现在 feed 上，只在主页显示，正好符合这个顺序。

#### 这时候「身份自述帖」升级为唯一的职业入口

当 feed 和昵称都不露职业时，身份自述帖从「转化开关」
升级为**唯一的职业入口**，优先级要提到最高。

实证：一个 2,196 粉的账号，前 3 年发 49 条全是生活、零线索；
第 50 条第一次写身份自述——**只有 108 赞**，
但 **8 小时内**出现第一条「怎么联系」，之后 6 个月持续收线索（含实盘客户）。

> **转化的开关不是「攒多久」，是「什么时候开口说自己是干什么的」。**

## 交付自检

- [ ] `forbidden_topics` 非空
- [ ] 商业定位具体到「卖什么给谁」
- [ ] 五要素里的**道具**没有留空
- [ ] 爱好分了 A/B/C 且标了内容线
- [ ] 三个超级符号指向同一件事
- [ ] 没有任何字段是我替用户猜的

最后复述完整定位，问：**「哪里读着不像你？」**
不像的地方就是错的地方，回到对应步骤重做。

## ★★★ 账号论点 ≠ 配比规则

大多数 `profile` 里写的是**配比规则**（「生活 8 : 职业 2，行业内容只做软植入」）——
它规定**行业出现多少**，**没有回答「这个人凭什么值得看」**。

**论点回答后一个问题，而且它是一条真因果链：**

```
配比规则   行业内容不超过 2/10                    —— 管密度
论点       「因为做了 X，我才有了现在这种生活」     —— 管为什么
```

### 🔴 论点不是硬桥，区别在真假因果

| | 硬桥 | **论点** |
| --- | --- | --- |
| 结构 | **假类比**（「打球和选房一样都看三点」） | **真因果链** |
| 观众反应 | 一眼看穿在铺垫广告 | 「哦，所以他能这样」 |
| 频率 | 每条都得说一次 | **账号层成立一次就够** |

### ★★ 关键判据：论点在账号层成立一次，不在每条内容里重复

一旦观众知道那条因果链，**之后每一条生活内容都自动是证据 —— 不用再说。**

这才是「行业内容是里子不是面子」的正确读法：
**里子不是「藏起来」，是「说一次，然后由生活内容替它说话」。**

| ✅ | 🔴 |
| --- | --- |
| 用一整条内容线讲清因果（= 身份自述，唯一的职业入口） | 每条生活内容结尾都拐回行业 |
| 生活内容里偶尔一句「我能这样是因为 X」，说完就走 | 讲「所以你也应该做 X」 |
| **什么都不说** —— 观众看多了自己会得出结论 | 用生活画面给行业内容做包装 |

⚠️ **论点解释了为什么配比是对的，没有授权把职业侧调大。**

### ★ 8:2 的含义因此变了

```
之前   生活 8 是触达基础，职业 2 是变现 —— 两个桶，要隔离
现在   生活 8 是论点的证据，职业 2 是机制说明 —— 一条因果链的两端
```

---

## ★★ 起点交代：「凭什么这不是炫耀」的唯一答案

当用户开始展示自己拥有的东西（资产、成绩、作品），**必然会撞上「这是不是在晒」。**

```
没有起点交代   「我有这四处房产」          = 晒结果
有起点交代     「我拿到过一笔钱，这是我用它做的事，中间算错过这些」  = 讲过程
```

**这不是谦虚问题，是结构问题。**

一个真实用户问「我不是白手起家，网友接受度高吗」——
**「接受度」是错的问题。**正确的问题是：**它在论点里是什么位置。**

| | |
| --- | --- |
| **一** | 交代起点把论点从「我很厉害」改成「**这笔资源可以这么用**」。前者只能仰视，后者对观众有用 |
| **二** | 它**命中真实客户画像** —— 会成为客户的人，恰恰是**手上有某种资源、不知道怎么用**的人。说出来是同类，不说是隔阂 |
| **三** | **省略起点才是攻击面** —— 任何人都能问「你哪来的本钱」，**藏起来的才是把柄** |

⚠️ 讲法：**一句背景，早段说，说完就走，不做成内容。**
🔴 **两个风险**：它会变成账号主题（「起点是否公平」是 dead end：吵得很热，一个客户都不来，
必须一次说清、追问不接）；**它常常涉及第三方**（家庭、配偶）——**先过对方。**

## ★ 按可反查性定披露粒度 —— 不是按「敏感程度」

用户说「这个不要透露」时，编导默认按**敏感度**处理（越私密越不说）。**错。**
正确标准是**可反查性**：说出来的组合，能不能被搜到唯一的那一个。

| 同样是「说城市」 | 判断 | 为什么 |
| --- | --- | --- |
| 独栋住宅 + 城市 | ✅ 能说 | 一城内上万套，**不可枚举** |
| 特种商业物业 + 城市 + **租户行业** | 🔴 **不能同时说** | 三者一交叉，**一搜就到** |
| 稀有物业类型 + 城市 | 🔴 不能说 | 一城内可枚举 |

**处方**：**不是"都别说"，是"二选一"。**
```
✅ 说城市，行业模糊掉
✅ 说行业，城市不提
🔴 两个一起说
```

⚠️ 这个判断**用户自己往往做不出来** —— 他知道哪些是秘密，
但不知道**哪两个非秘密的信息交叉之后会变成秘密**。**这是编导该主动算的。**

⚠️ 还有一层常被忘记：**被讲的那一方会刷到**（租客、同事、客户）。
讲他们只讲**我这边的观察和麻烦**，不讲他们的经营。

## ★ 「欢迎联系」的三条构造规则

用户要求「表达出欢迎大家联系，用正确的姿态」时，先看 `profile.tone` 里有没有内部原则。
一个真实样本给的是：**「忙碌是最好的邀请」「先让人看见在干活，再轻轻推开一扇门」。**

### 三种错法

| | 长什么样 | 错在哪 |
| --- | --- | --- |
| **求人** | 「欢迎大家联系我」 | **缺前半** —— 没让人看见在干活，直接要 |
| **爱来不来** | 只展示，什么门都不给 | **缺后半** —— 没门就没转化 |
| 🔴 **此地无银** | 「我不是要拉活儿，只是……」 | **解释自己不是在推销，本身就是推销** |

### 三条构造规则

| | |
| --- | --- |
| **1 · 门要具体，不能是身份邀请** | ❌「欢迎联系」 ✅「**你算完的数发我**」—— 一个动作，不是一个身份 |
| **2 · 我出现的身份是「正在做事的人」** | ❌「我是做 X 的，有需要……」 ✅「**这份清单是我这次自己跑的**」 |
| **3 · 不解释动机** | 说完就走，不接下文 |

### ★★ 最容易犯的错：把 CLOSE 当成每条的标配

```
若 profile 写「每 3 条 ≤1 次」：
65 条  →  最多 21 条带 CLOSE，其余 44 条什么都不说
```

**「欢迎大家联系」最好的表达方式，是大部分时候不说。**
说得少，那几次才有重量 —— 这是「忙碌是最好的邀请」的操作版本。

★ 生活内容的默认 CLOSE 只有两个：**「你那边呢？」**（只邀请说话，不邀请找我）
和 **什么都不说**。

## ★★ 可信度靠反证，不靠证据 —— 一个可复制的结构

一个真实账号的论点是「**因为做了 X，我才有了现在这种生活**」。
按常规做法，编导会去收集**支持它的证据**（资产、成绩、作品）。
**收集得越多，看起来越像广告。**

那个账号最后长成的结构是：

```
论点        因为做了 X，我才有了现在这种生活
物证        我确实有这些                     ← 支持
反证一      我的身体数据不同意               ← 生理层
反证二      我的钱是借来的，我还是必须工作     ← 结构层
```

**两个反证 + 一个物证 —— 这个账号就不是在卖梦。**

### 为什么反证比证据更有用

| | 观众得到 | 结果 |
| --- | --- | --- |
| 只给证据 | 「他很成功」 | 仰视 → 不联系 |
| **证据 + 反证** | 「**他这条路是这样的，代价是这些**」 | 对照 → **有人会来问** |

### ★ 怎么找反证（三个抽屉）

| 抽屉 | 长什么样 |
| --- | --- |
| **身体 / 数据层** | 可穿戴设备、体检、睡眠 —— **一个和自我感觉矛盾的客观数字** |
| **结构层** | 收入的真实构成、负债、被动收入的实际比例 —— **「成功」背后的机制约束** |
| **时间层** | 那件事之后的实际生活，和当初以为的差在哪 |

⚠️ **反证必须是真的。**编造一个可爱的缺点（「我就是太拼了」）比不给反证更糟 ——
那是伪装成反证的证据，观众能闻出来。

### ★★★ 上位概念：从「分享」升到「样本」

一个真实用户给出的动机是「**希望我的故事能给观众一些启发，帮到他们**」。
这句话把定位从**分享**推到了**样本**：

```
分享   我遇到了，给你看
样本   ★ 我是一个可以被研究的案例 —— 包括我的代价和失败
```

**推论：样本必须包含代价，否则就是广告。**
**这条是反证线的授权来源** —— 有了它，自曝短处不是自黑，是履行样本的定义。

⚠️ 但**样本 ≠ 教人怎么做**。样本只提供「我这里发生了什么」，不提供「你应该怎么办」。

## ★ 形态没定之前，不要下达制作要求

一个真实失误：编导连续三次要求用户「**边做边留素材**」（拍画面、录语音备忘、存文件），
理由是「以后补不回来」。

用户最后说：**「这个没啥要跑的，大概率就是口播复盘。」**

```
编导默认的形态   跟拍连载  →  必须现场留素材
实际的形态       口播复盘  →  什么都不用留
```

**要求本身没错，错在它建立在一个没确认过的形态假设上。**
而这类要求代价很高 —— 它给用户增加了持续性的负担，**而用户会照做，直到有人发现它没必要**。

| 顺序 | |
| --- | --- |
| ✅ | **先问形态**（跟拍 / 口播复盘 / 图文）→ 再谈这个形态需要什么 |
| 🔴 | 先下达制作要求 → 用户默默照做 → 几周后发现白做 |

⚠️ 尤其注意：**「以后补不回来」这个理由听起来很有力，会让编导跳过形态确认。**
口播复盘里，那些「补不回来」的东西**根本不需要**。
