# 1 · 账号定位

**产出**：`profile.yaml`（全流程地基）
**方法论**：`references/method-account.md`

---

## 顺序不能改

```
商业定位 → 内容定位 → IP 策划 → 账户搭建 → 超级符号
（怎么赚钱）（拍什么）  （人设）   （门面）    （记忆点）
```

**商业定位排第一**。做广告变现和做咨询转化，后面每一步的取舍都不同。

---

## 第一步 · 商业定位

问：**你有产品要卖吗？**

| 有 | 无 |
|---|---|
| 电商（原则：少即是多）<br>咨询 | 广告 |

追问到具体：卖什么、客单价、谁买、多久买一次。

**若同时有多个变现目标**，做合并检查：

> 「这几个目标，能不能用同一批内容覆盖？」

多数人的多个目标能归成**两条内容线**，各自溢出覆盖另一个。
目标数 ≠ 内容线数——这一步能省一半工作量。

---

## 第二步 · 内容定位

```
主题 IP（内容为主）    人物 IP（人为主）
```

判断法：**换个人来做，这个号还成立吗？**

---

## 第三步 · IP 策划（五要素）

| 要素 | 追问 |
|---|---|
| 身份 | 你是谁？凭什么讲这个？**你每天真的在做这件事吗？** |
| 场景 | 内容发生在哪？固定还是流动？ |
| 道具 | 有没有一个能反复出现的物件？ |
| 态度 | 温和还是锋利？你会不会拒绝什么？ |
| 呈现 | 出镜 / 口播 / b-roll / 图文？ |

**身份那一问是关键**。经常问出矛盾——有人说自己是某身份，但不参与日常。
**可信度身份 ≠ 日常工作身份**：前者只配一句话背书，撑不成内容。

---

## 第四步 · 逼出禁区 ★ 最重要，不能跳

依次问：

1. 你的身份里，有哪部分是真的但你不想做成内容的？
2. 有什么是别人以为你会做、但你其实不做的？
3. 过去的职业、放弃的爱好、不参与的业务环节，有哪些？
4. **什么内容你发出去会心虚？**

每条追问一句：**「这个是完全不提，还是可以当注脚提一句？」**

分两类记录：
- `forbidden_topics` —— 完全不做
- `identity_fragments` —— 只做注脚，带 `usage` 和 `max_per_month`

**第 4 问的答案往往最有价值。心虚感几乎总是指向身份不实。**

一份没有 `forbidden_topics` 的 profile 是废的。

---

## 第五步 · 内容支柱与爱好分层

列出真正在做、拍得出来的爱好/领域，按**离成交多远**分三层：

| 层 | 定义 | 用法 |
|---|---|---|
| A | 能自然桥接到变现主题 | 主推，转化 |
| B | 拉泛流量，不指望转化 | 主推，拉新 |
| C | 只做背景质感 | 不单独成篇、不进标题 |

再给每项标**服务哪条内容线**。

**硬规则：每月只主推 2 个**（建议 1A + 1B，且两条线各覆盖一个）。
全都做支柱等于没有支柱。

---

## 第六步 · 账户搭建与超级符号

四件套：头像 · 昵称 · 头图 · 简介

**昵称两标准**：有记忆点且顺口、有信息量。

**简介是身份的主要承载体**——身份靠简介说清，不靠每条内容重复。
必含：职业 / 地点 / 差异化 / 资质。禁用：欢迎咨询、全程服务、求关注。

**超级符号**：MI 理念 · BI 行为 · VI 视觉，三者指向同一件事。

---

### 顺序设计：feed 不露职业，主页才露

对不想一上来就暴露职业的用户很有用：

```
feed 层不露职业（昵称是地点 / 生活向）
        ↓
主页层露职业（简介 + 资质编号）
```

效果是「**点进来才知道他是干什么的**」。这不是妥协，是可设计的顺序。

**代价要说清楚**：昵称不带职业 = **放弃被搜索找到**。
此时**平台 ID（redId 等）成为唯一还能承担可搜索性的位置**——
它不出现在 feed 上，只在主页显示，正好符合这个顺序。

#### 这时候「身份自述帖」升级为唯一的职业入口

当 feed 和昵称都不露职业时，身份自述帖从「转化开关」
升级为**唯一的职业入口**，优先级要提到最高。

实证：一个 2,196 粉的账号，前 3 年发 49 条全是生活、零线索；
第 50 条第一次写身份自述——**只有 108 赞**，
但 **8 小时内**出现第一条「怎么联系」，之后 6 个月持续收线索（含实盘客户）。

> **转化的开关不是「攒多久」，是「什么时候开口说自己是干什么的」。**

---

## 交付自检

- [ ] `forbidden_topics` 非空
- [ ] 商业定位具体到「卖什么给谁」
- [ ] 五要素里的**道具**没有留空
- [ ] 爱好分了 A/B/C 且标了内容线
- [ ] 三个超级符号指向同一件事
- [ ] 没有任何字段是我替用户猜的

最后复述完整定位，问：**「哪里读着不像你？」**
不像的地方就是错的地方，回到对应步骤重做。
